**Goal:** 完成可维护、发布并在网页和小程序实际使用的场景后台，同时提供音频、用户、统计和操作记录。

**Architecture:** 扩展现有独立管理端与 Spring Boot 后端，采用 DTO、服务事务和数据库分页。官方内容以服务端为准，用户本地自建对话保留。新增持久化音频目录与元数据，不改动既有静态音频。

**Tech Stack:** Java 21 / Spring Boot 3.2.5 / JPA / MySQL；React / TypeScript / Vite / Vitest；Taro。沿用锁文件，不顺手升级依赖。

## Global Constraints

- 第一版范围：数据概览、场景与台词管理、音频管理、用户管理、管理员登录和操作记录。
- 状态为草稿、已发布、已下架；内部值为 DRAFT、PUBLISHED、OFFLINE。
- 支持 MP3、WAV，每个文件最多 20 MB；实现精确定义为 20 × 1024 × 1024 字节，界面注明。
- 已有官方内置场景迁移为已发布，保留原 ID、编码、台词与静态音频引用；已有用户自建场景保留归属。
- 详情只读，不返回密码哈希、微信标识或完整手机号，不展示原始学习状态 JSON。
- 日志按北京时间展示；不展示无法由现有数据证明的日活、学习次数和热门榜。
- 先读根目录现状入口及目标仓库说明；保留所有既有改动、素材、模型和密钥文件。根目录 version.json 不作为应用版本使用。
- 各仓库独立核对和提交，只纳入本任务差异。复用当前工作区，因为当前未提交的配音代码也是必须保留的基线；不得新建旧 HEAD 的检出后覆盖这些功能。
- 本计划仅本地实现及验证，不自动推送、部署或运行生产数据库迁移。

## 当前代码核对与边界

2026-10-14 已读 yue-admin/README.md、相关实际代码与四仓库 Git 状态。yue-backend 无根 README；参考根现状入口、pom.xml 和服务源码。四仓库均有其他未提交内容，尤其 yue-backend 的配音过滤器为当前未跟踪代码。

网页 SceneDialogueScreen、小程序 dialogue 和 dlgdetail 仍读取 DIALOGUES 常量与本地自建数据；当前并未接入服务端场景。为保留现有免登录浏览体验，新增只读 `/api/public/scenes` 与 `/api/public/scenes/{id}`，只返回已发布官方内容；原 `/api/scenes` 继续要求登录，包含可见官方内容及当前用户云端自建场景。公共端点不返回收藏信息或用户数据。

既有 DubbingUploadFilter 会把非配音 multipart 限为 2 MiB。必须仅为管理员音频上传设置 21 MiB 请求包上限，服务端仍严格执行 20 MiB 文件上限，其他接口额度不变。生产当前使用数据库 validate，开发默认 update；提供显式迁移，不靠自动建表完成上线。

## 文件职责与接口约定

- 后端 `admin/`：AdminController 保留认证与读接口，新增 AdminSceneController、AdminAudioController；AdminSceneService、AdminQueryService、AdminAudioService 分别负责场景、查询、文件事务协调；AdminDtos.java 定义管理 DTO；AdminAuditService 写日志。
- 后端 `entity/` 和 `repository/`：扩展 Scene/SceneLine，新增 AudioResource、AdminAuditLog 与仓库；SceneRepository 支持条件分页及可见性查询。
- 后端 `controller/PublicSceneController.java`、`service/SceneService.java`：统一用户端可见性；`controller/AudioResourceController.java` 提供受限路径下音频读取。
- 管理端 `src/api.ts` 负责认证、JSON/空响应和 FormData，`src/types.ts` 维护类型；`src/App.tsx` 管布局，`src/pages/` 管各业务页，`src/components/` 管台词编辑与音频选择。
- 两用户端各自 `src/lib/scene-api.ts` 映射服务端 SceneResponse 到原 Dialogue；不跨仓库导入源码。
- 管理列表统一 `PageResult<T>(items,total,page,pageSize)`，page 从 1 开始，pageSize 默认 20、最大 100。
- `SceneSaveRequest(code,title,place,emoji,roleA,roleB,category,difficulty,sortOrder,version,lines)`；台词 `LineInput(speaker,cantoneseText,mandarinText,jyutping,audioKey)`，顺序由数组确定。create 不接受归属及状态；update 必须带 version。
- `SceneDetail(scene,lines)` 包含 version，创建官方草稿并设置 builtin=true、ownerUserId=null。编码创建后不可变。
- 音频 `AudioItem(id,name,audioKey,url,size,contentType,referenceCount,readOnly,version)`；静态资源 id 使用 `static:` 前缀、上传资源使用 `upload:` 前缀。读取 URL 为既有 `/audio/…` 或新 `/audio/uploads/{opaqueId}`，不接受任意磁盘路径。
