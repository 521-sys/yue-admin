# 粤语学习后台第一版设计

日期：2026-10-13。状态：待用户审阅，尚未实施。

## 目标与已确认范围

用户已确认第一版包含数据概览、场景与台词管理、音频管理、用户管理、管理员登录和操作记录。目标是让运营人员无需修改代码即可维护官方粤语对话内容，并让用户端看到发布后的内容。

默认面向少数运营人员，沿用当前配置式管理员账号。第一版不加入影视库、词汇库、AI 配置、多角色权限或用户封禁。

## 现状与实现选择

沿用 yue-admin 的 React/Vite 管理端，以及 yue-backend 的 Spring Boot 接口和数据库。当前后台提供登录、用户与场景数量、用户列表、场景列表；已有场景增删改接口，但缺少完整管理页面和台词编辑。用户端目前读取场景时没有发布状态过滤。学习数据保存在每个用户一条的 learn_state JSON 中，不能直接推导可靠的学习次数。

选择扩展现有工程：保留已有登录体系与用户端接口，按职责拆分管理页面和管理服务。直接继续堆在单文件中的改法修改量较少，但不适合新增音频和发布流程；重建独立内容服务会增加部署与数据同步成本，本期不采用。

## 页面与操作

### 1. 数据概览

展示用户总数、官方场景总数、已发布场景数、音频资源数、缺失音频的台词数及最近操作记录。统计明确区分官方和用户自建场景。真实数据为空时显示零；请求失败显示错误，不展示模拟统计。本期不展示日活、学习次数或热门榜，因为尚无相应事件数据。

### 2. 场景与台词

列表支持关键词搜索、分类与状态筛选、分页和排序。场景包含稳定唯一编码、标题、地点、图标、分类、初级/中级/高级难度、角色 A/B、排序值、发布状态。编码创建后不可变；默认分类为日常生活，难度为初级。

详情编辑页统一维护场景和台词。每句包含角色、粤语原文、普通话释义、可选粤拼、可选音频及顺序。支持添加、删除、上下移动、试听和对话预览。整份场景与台词在一次事务中保存，避免出现半份对话或排序冲突。保存失败保留表单内容；未保存离开提示。

新场景默认草稿。发布前必须有完整场景资料和至少一条有效台词；缺少音频给出提示，但允许发布文字内容。状态为草稿、已发布、已下架。发布后的内容可直接编辑并保存生效，本期不做已发布版本与待审版本并存；编辑页明确提示保存影响线上内容。

已发布内容先下架再删除；删除需确认，并在事务中清理相关台词和所有用户的对应收藏。音频独立保留，避免误删共享素材。修改使用版本字段检测过期表单，冲突返回提示，不覆盖别人的修改。

后台可查看场景来源；本期仅编辑官方场景。用户自建场景由原有用户功能维护，不会因后台迁移自动变为官方公共内容。

### 3. 音频管理

支持音频列表、名称搜索、分页、上传、试听、替换、查看关联台词和删除。支持 MP3、WAV，每个文件最多 20 MB；服务端验证文件类型、大小及文件名路径安全。内部文件名使用生成的唯一标识，不使用上传文件名作为存储路径。

既有静态音频保留原地址并可选用，作为只读资源展示；新增音频存入配置的持久化目录，不写入源码或打包文件。上传资源通过统一音频读取接口提供访问，管理写操作要求管理员身份。台词保留兼容的 audioKey 引用，接口提供可播放地址，用户端按实际读取逻辑接入。

替换使用新文件、更新资源引用的方式，已关联台词随之使用新版本；界面提示关联数量。被引用资源禁止删除。数据库写入失败清理本次新文件；替换完成后再清理旧文件，清理失败记录服务日志供处理。上传目录及数据库需一起备份。

### 4. 用户管理

支持按用户名或昵称搜索、分页、查看详情。展示用户 ID、昵称、脱敏手机号、注册时间、最近学习状态同步时间、可解析的学习进度摘要与收藏。学习状态缺失或格式异常时显示暂无数据，不导致整个页面失败。

详情只读，不返回密码哈希、微信标识或完整手机号，不展示原始学习状态 JSON。最近同步时间明确标为同步时间，不当作最近登录时间。

### 5. 登录和操作记录

沿用管理员账号配置与管理员 JWT。未配置密码哈希时无法登录，不添加默认密码。所有管理接口校验管理员角色；未认证返回 401，普通用户访问返回 403。登录过期清除后台专用 token 并返回登录页；退出不清空其他应用会话数据。

操作记录保存管理员标识、操作类型、对象 ID、简短变更摘要、时间。场景与台词保存、发布、下架、删除和音频变更均记录。内容变更与对应数据库日志在同一事务提交；不记录密码、token、完整用户资料或音频二进制。列表可按类型和日期筛选并分页，按北京时间展示；第一版不提供修改或删除日志功能。

## 数据与接口

Scene 新增 category、difficulty、sortOrder、status、version、updatedAt；SceneLine 新增可选 jyutping。新增音频资源元数据表和管理员操作日志表。

使用明确的数据库迁移脚本及部署步骤。已有官方内置场景迁移为已发布，保留原 ID、编码、台词与静态音频引用；已有用户自建场景保留归属。迁移必须能重复执行而不重复创建数据，不在应用每次启动时重置运营内容。

管理接口统一位于 /api/admin：dashboard、scenes、scenes/{id}、scenes/{id}/status、audio、audio/{id}、users、users/{id}、audit-logs。创建与整份编辑场景使用独立 DTO，不直接绑定数据库实体。列表响应统一包含 items、total、page、pageSize；分页有服务端上限。删除成功支持空响应。

管理端读取表单并提交 DTO，后端校验与事务保存，用户端通过原有场景接口读取。官方场景仅已发布状态对普通用户可见；列表、详情、收藏读取及新增收藏一致校验。用户自建场景仅创建者可见。官方内容下架后已存在收藏不删除，但不再返回或允许通过旧 ID 访问；重新发布后收藏恢复可见。

错误以可读信息返回：400 参数错误、401 未登录、403 无权限、404 不存在或普通用户不可见、409 编码或编辑版本冲突/资源被引用、413 文件过大、415 文件类型不支持。管理端每页提供加载、空数据、请求失败和重试状态。

## 用户端接入与边界

检查 Web 和小程序场景数据来源。后台发布的场景应通过服务端接口展示；需要时补齐已有页面的数据接入和音频地址解析。若存在本地内置场景回退，不能让其绕过服务端下架状态。保留原有跟读、收藏及用户自建流程，不改造 AI 或电影模仿功能。

## 验收

1. 管理员能创建茶餐厅点餐草稿，设置角色，添加多句台词、粤拼与音频，调整顺序并预览。
2. 草稿在普通用户列表、详情和收藏接口不可见；发布后用户端展示且可播放；下架后旧链接也不可访问。
3. 重新发布保留原收藏；删除正确清理台词及收藏，音频仍保留。
4. 音频上传后可选用和试听；错误类型或超限文件被拒绝；关联中音频不可删除。
5. 用户列表分页与搜索可用，详情只展示脱敏数据；异常学习状态不会导致页面报错。
6. 普通用户不能访问管理接口；过期登录跳转登录页；关键变更均能在操作记录中找到。
7. 后端测试覆盖身份权限、状态隔离、场景台词事务、编辑冲突、音频校验及引用保护；前端测试覆盖编辑发布、错误保留输入、上传和会话失效。
8. 运行现有相关测试及管理端构建，检查实际页面；无法运行的环境依赖明确记录，不以静态检查替代通过声明。

## 实施顺序与现有工作保护

先做数据迁移及管理服务，再完成场景发布和用户端可见性、音频、用户详情、概览日志及后台页面，最后联调验证。当前 yue-backend/media-worker 下存在未提交的 ASR/配音相关文件，实施时保留，不纳入本次修改。部署和线上数据库变更不在本地实现阶段自动执行。
