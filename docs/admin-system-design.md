# 粤语学习后台管理系统设计

## 目标

为少数运营人员提供一个独立的桌面端后台，用于维护场景对话内容、管理台词和音频引用，并查看用户及学习数据概览。后台与现有用户端 Web、小程序共用 Spring Boot 后端和数据库。

## 范围

首期包含：管理员登录、数据概览、场景列表与编辑、场景台词编辑、用户列表与详情。

首期不包含：完整 RBAC、多租户、操作审计、词典/词汇库迁移、批量导入导出、在线音频上传。音频继续使用现有静态资源，通过 `audioKey` 维护引用。

## 用户与权限

后台面向少数可信运营人员。管理员账号通过后端配置提供，登录后签发带管理员身份声明的 JWT。所有 `/api/admin/**` 接口都必须校验管理员身份；普通用户 JWT、缺失 token、过期 token 分别返回 403 或 401。首期不增加角色表和权限表，保留后续升级 RBAC 的边界。

## 系统结构

### 管理端前端

新增 `yue-admin` 独立 React/Vite/TypeScript 工程，使用桌面宽屏布局。路由包含：

- `/login`：管理员登录
- `/dashboard`：用户数、场景数、学习活跃度等概览卡片
- `/scenes`：场景列表、搜索、分页、创建、编辑、删除
- `/scenes/:id`：场景基本信息和台词编辑
- `/users`：用户列表、搜索、分页
- `/users/:id`：用户基础资料和学习数据只读详情

前端通过统一 API 客户端附带 JWT。401 清理本地 token 并跳转登录页；403 显示无权限；表单提交失败保留输入并显示后端错误。

### 后端接口

新增管理控制器和服务层，接口边界如下：

- `POST /api/admin/auth/login`
- `GET /api/admin/dashboard`
- `GET /api/admin/scenes`
- `POST /api/admin/scenes`
- `GET /api/admin/scenes/{id}`
- `PUT /api/admin/scenes/{id}`
- `DELETE /api/admin/scenes/{id}`
- `POST /api/admin/scenes/{id}/lines`
- `PUT /api/admin/scenes/{id}/lines/{lineId}`
- `DELETE /api/admin/scenes/{id}/lines/{lineId}`
- `GET /api/admin/users`
- `GET /api/admin/users/{id}`

列表接口提供分页和必要的关键词过滤。用户响应脱敏手机号和微信标识；不返回密码哈希。删除场景前检查关联台词并由服务层在事务中处理，失败时返回可读错误。

## 数据流

管理员登录得到 JWT，管理端保存在浏览器会话存储并在每次管理请求中发送。场景列表读取 `scenes`；场景详情读取 `scene_lines`；用户列表读取 `users`，用户学习详情读取 `learn_state`。管理端不直接访问数据库，也不复用普通用户的写入接口。

## 错误处理

后端沿用现有全局异常处理器，统一返回 JSON 错误。参数校验失败返回 400；未认证返回 401；身份不足返回 403；目标不存在返回 404；冲突或关联数据阻止删除返回 409。前端在列表、详情、保存、删除四类操作中分别显示加载、空状态和错误状态。

## 验证策略

后端测试管理员登录、管理员接口访问、普通用户拒绝访问、场景和台词 CRUD、用户分页与脱敏。前端测试登录态恢复、路由保护、场景编辑提交、分页筛选和 401/403 错误态。构建验证执行后端 `mvn test` 和管理端 `npm test`、`npm run build`。

## 后续扩展边界

后续可在不改变管理端页面边界的情况下增加管理员表、角色权限、审计日志、词汇实体及批量导入；这些能力不纳入首期实现。
