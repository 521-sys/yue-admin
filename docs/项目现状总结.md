## 后台管理系统进度及已知问题

已确认需求：少数运营人员使用独立 yue-admin，复用后端，首期支持登录、概览、场景和台词维护、用户列表和详情。完整 RBAC、词库迁移与在线音频上传不属于本期。

目前前端仅有登录、总量卡片、用户列表和场景占位页，尚未达到交付范围。

检查发现的具体问题：
1. 后端 application.yml 在 logging 下重复定义 admin，且与服务读取的 admin.username/admin.password-hash 路径不一致；可能导致启动失败或管理员配置无法生效。
2. 用户列表使用 Map.of，手机号为空时 mask 返回 null，会导致异常；尚无分页、搜索、详情和学习数据统计。
3. 场景与台词管理 API 尚未实现。
4. 管理端 401 处理未同步 React 登录状态；用户列表请求失败缺少完整处理；尚无实际页面路由和配套测试。
5. yue-admin 未配置 .gitignore，本地初次提交跟踪了 3880 个文件，包含依赖或构建目录；发布前需要整理，不应直接推送该提交。
6. 管理员权限边界、普通用户接口兼容性、表单校验与错误响应尚需测试。
